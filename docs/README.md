## Document Overview

### Accounting PRD Highlights

The Accounting PRD covers all aspects of the financial management system for the car rental business:

- **Financial Tracking**: Daily cash flow monitoring and per-vehicle profitability
- **Revenue Recognition**: Payment reconciliation-based revenue recognition
- **Depreciation**: 60-month straight-line depreciation for all vehicles
- **Payment Methods**: Support for both manual CSV import and real-time online reconciliation
- **Integration**: CSV-based integration with Oracle General Ledger
- **Compliance**: 10-year data retention with immutable ledger journals
- **Taxation**: VAT-only with configurable tax rules
- **Reporting**: 6 types of statutory reports including income, maintenance, and fleet availability
